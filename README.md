# Product page scaffold

This branch (feature/product-page) contains a small Vite + React + Tailwind scaffold and a single ProductPage component using placeholder images.

Quick start:

1. npm install
2. npm run dev

The product data is in data/products/ewe.json and images live in public/images/products/ewe/. Replace the SVG placeholders with your real images (keep the filenames or update the JSON).

The Enquire button opens the Wix form URL mapping reused from your index.html.
